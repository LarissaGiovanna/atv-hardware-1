# atv-hardware-1
Atividade de Infraestrutura de Hardware feita em grupo (6 pessoas).

## Pastas:
- `/logisim`: arquivos do projeto do Logisim, com entradas e saídas rotuladas exatamente como na especificação
- `/modelagem`: registro da Etapa 1 (tabela verdade ou tabela de estados, expressões, passos de simplificação, diagrama)
- `/verilog`: arquivos de descrição em Verilog e testbench

### Outros arquivos:
- `conceito.md`: resposta à questão conceitual do tema, entre 5 e 10 linhas, com justificativa técnica
- `README.md`: sobre do projeto

## **OBS:**
- Mandar uma pasta compactada com o nome temaNN_sobrenome1_sobrenome2.zip, onde o nome e sobrenome são os do representante do grupo.
- Deixar os arquivos na raiz do projeto
